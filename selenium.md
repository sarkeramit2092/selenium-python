# Selenium Overview

## 🔎 What is Selenium?
Selenium is an open-source tool used for automating web browsers. It is primarily used for automated testing of web applications, but can also automate repetitive browser tasks.

---

## 🚀 Key Features
- **Supports multiple languages**: Python, Java, C#, Ruby, etc.
- **Works across browsers**: Chrome, Firefox, Edge, Safari.
- **Cross-platform support**: Windows, macOS, Linux.
- **Powerful browser control**: Can click buttons, fill forms, scrape data, etc.

---

## 🔧 Selenium Components
### 1. Selenium WebDriver
- Controls browser actions directly.
- Most commonly used Selenium component.

### 2. Selenium IDE
- Record and playback tool.
- Best for beginners.

### 3. Selenium Grid
- Enables parallel execution.
- Supports distributed testing across multiple machines.

---

## 🛠️ Selenium Architecture
```
Test Script (Python/Java/Other)
         ↓
Selenium WebDriver API
         ↓
Browser Driver (like chromedriver.exe)
         ↓
Web Browser (Chrome, Firefox, etc.)
```

---

## 🚪 What Can Selenium Do?
- Open URLs in browsers
- Click elements, fill forms
- Scrape data
- Handle popups and alerts
- Take screenshots
- Run tests across browsers
